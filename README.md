# ABD Cipher

**Versión 1.0**

ABD Cipher es una aplicación desarrollada en Python que permite realizar cifrados y descifrados mediante una alternativa del método César.

## Características

- Cifrado César.
- Descifrado César.
- Aplicación empaquetada para Windows.

## Tecnologías utilizadas

- Python.

## Ejecución

Puedes ejecutar la aplicación desde el archivo `dist/ABD Cipher.exe`.
